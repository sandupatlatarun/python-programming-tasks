\# Task 1 - Voice Assistant



A Python-based voice assistant that listens to spoken commands and responds using text-to-speech.



\## Features



\- Voice input using SpeechRecognition

\- Text-to-speech using pyttsx3

\- Greeting commands

\- Current time

\- Current date

\- Google web search

\- Live weather information using OpenWeatherMap

\- Timed voice reminders

\- Intent classification

\- Microphone and speech-recognition error handling



\## Technologies Used



\- Python

\- SpeechRecognition

\- PyAudio

\- pyttsx3

\- Requests

\- python-dotenv

\- datetime

\- threading

\- webbrowser
