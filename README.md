\# Python Programming Tasks



This repository contains three Python programming projects completed as part of the Python programming tasks.



\## Tasks



\### Task 1 - Voice Assistant



A Python-based voice assistant that accepts spoken commands and responds using text-to-speech.



Features include:



\- Voice input using SpeechRecognition

\- Text-to-speech using pyttsx3

\- Greeting commands

\- Current time

\- Current date

\- Web search

\- Weather information using OpenWeatherMap

\- Timed reminders

\- Intent classification

\- Error handling



Project folder:



`Task-1-Voice-Assistant`



\---



\### Task 2 - Advanced BMI Calculator



A graphical BMI calculator built with Tkinter.



Features include:



\- GUI using Tkinter

\- Weight and height input

\- Height input in centimeters

\- BMI calculation

\- BMI category detection

\- Color-coded BMI result

\- BMI range guide

\- SQLite database

\- BMI history

\- BMI history graph using Matplotlib

\- Clear inputs

\- Clear BMI history

\- Input validation



Project folder:



`Task-2-Advanced-BMI-Calculator`



\---



\### Task 3 - Random Password Generator



A Python password generator that creates secure random passwords.



Features include:



\- User-defined password length

\- Uppercase letters

\- Lowercase letters

\- Numbers

\- Special characters

\- Input validation

\- Multiple password generation

\- Cryptographically secure generation using Python's secrets module



Project folder:



`Task-3-Random-Password-Generator`



\---
