\# 🔐 Random Password Generator



A simple Python program that generates secure random passwords of a user-specified length.



\## Features



\- Generates random passwords

\- Supports letters, numbers, and special characters

\- Uses Python's `secrets` module for secure random generation

\- Validates password length

\- Handles invalid user input

\- Allows generating multiple passwords



\## Requirements



\- Python 3.12 or later

\- No external packages are required
